# Portfolio Presentation Guide

## CV project entry

**Discount Label Optimization — End-to-End Data Analytics Project**  
Built an end-to-end analytics solution using Python and Power BI, cleaning and integrating 150K+ records, segmenting 300+ stores with DBSCAN and K-Means, and evaluating classification models to identify patterns associated with successful discount-label sales. Final Random Forest model achieved F1 = 0.728 and ROC-AUC = 0.763 on the test set.
