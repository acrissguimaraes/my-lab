# Notebooks

The three notebooks below are the core analytical workflow for this project.

| Notebook | Purpose |
|---|---|
| `data_cleaning.ipynb` | Data diagnosis, cleaning, validation, feature engineering and export. |
| `store_segmentation.ipynb` | Store-level aggregation, DBSCAN outlier detection, K-Means segmentation and commercial profiles. |
| `sales_prediction_model.ipynb` | Classification pipeline, model comparison, Random Forest tuning, evaluation and feature importance. |

The notebooks use the cleaned Excel files as inputs, so the public repository intentionally does not include those source datasets.

The notebook names match the files currently uploaded to this repository.
