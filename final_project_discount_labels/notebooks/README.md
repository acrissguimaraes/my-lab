# Notebooks

The three notebooks below are the core analytical workflow for this project.

| Portfolio filename | Source notebook | Purpose |
|---|---|---|
| `01_data_cleaning.ipynb` | `data_clean(3).ipynb` | Data diagnosis, cleaning, validation, feature engineering and export. |
| `02_store_segmentation.ipynb` | `store_segmentation(1).ipynb` | Store-level aggregation, DBSCAN outlier detection, K-Means segmentation and commercial profiles. |
| `03_sales_prediction_model.ipynb` | `product_sales_prediction_model(1).ipynb` | Classification pipeline, model comparison, Random Forest tuning, evaluation and feature importance. |

The source notebooks were reviewed for this portfolio structure. They use the cleaned Excel files as inputs, so the public repository intentionally does not include those source datasets.

When uploading the notebooks, use the portfolio filenames above so the links in the project documentation remain clean and consistent.
