# Dashboard Preview

The final Power BI dashboard contains two complementary views.

## 1. Overview

The overview page presents the main commercial KPIs and allows the user to explore performance by time, brand, store, store type and district.

### Main KPIs

- **Total labels:** 150,023
- **Labels sold:** 80,482
- **Sell-through rate:** 53.6%
- **Potential profit:** €26,275
- **Realised profit:** €13,480
- **Realised / potential profit:** 51%
- **Average days to sale:** 0.93

### Main visuals

- Realised profit and sell-through rate by label date
- Top 5 brands by sell-through
- District performance map
- Sell-through by discount class
- Sell-through by product shelf life
- Sell-through by days of validity

## 2. Store Detail

The store-detail page focuses on operational comparison between locations.

### Main KPIs

- **Total labels:** 150,023
- **Sell-through rate:** 54%
- **Realised profit:** €13,480.03
- **Average margin:** 16%
- **Active stores:** 332

### Main visuals

- Waste rate versus potential profit by store
- Label volume by sales-area category
- Profit by brand
- Store profile table

This page connects naturally with the Python store-segmentation analysis, where stores are grouped using behavioural indicators such as sell rate, profit per label and average discount.

## Portfolio interpretation

The dashboard demonstrates the **Business Intelligence** layer of the project: it converts the cleaned analytical dataset into an interactive decision-support interface. The Python notebooks then extend the analysis into store segmentation and predictive modelling.
