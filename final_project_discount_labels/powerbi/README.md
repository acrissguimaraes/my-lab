# Power BI Dashboard

The Power BI component was created to turn the analytical work into an interactive business intelligence tool.

## Dashboard purpose

The dashboard supports exploration of:

- Sales performance
- Margin
- Waste
- Store performance
- Product performance
- Store segments
- Time periods
- Discount behaviour

Users can filter the analysis by store, product, segment and date.

## Deliverable

The original `.pbix` file is kept outside the public GitHub repository because this repository is designed to showcase the analytical workflow and results without redistributing the underlying source data.

The project presentation includes the dashboard concept and its role in supporting commercial prioritization.
