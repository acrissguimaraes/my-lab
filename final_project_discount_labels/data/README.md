# Data

The original datasets used during the project are not included in this public repository.

The analysis used two complementary sources:

- Product-level discount labels.
- Store-level characteristics.

The final analytical dataset contained 150,023 validated label records, 342 registered stores, 332 stores with label history, and 318 SKUs after cleaning.

The cleaning workflow is available in `../notebooks/01_data_cleaning.ipynb`.

This folder is intentionally kept free of the original Excel datasets. This makes the portfolio repository easier to share while avoiding unnecessary redistribution of source data.
